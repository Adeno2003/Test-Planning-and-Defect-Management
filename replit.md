# Running this project

This repository contains a React + TypeScript counter application for a test-planning and defect-management lab. Preserve the existing folder structure and lab behavior unless changes are requested.

## Development

- App directory: `StarterLab04/counter-app`
- Runtime: Node.js 20.19 or later (the configured Node.js 20 runtime is supported).
- Install locked dependencies: `cd StarterLab04/counter-app && npm ci`
- Run: use the **Start application** workflow, or run `cd StarterLab04/counter-app && npm run dev`.
- Vite serves on `0.0.0.0:5000`, with proxy hosts allowed for Replit Preview.
- No secrets, database, or external services are needed.

## Checks

- Build: `cd StarterLab04/counter-app && npm run build`
- Lint: `cd StarterLab04/counter-app && npm run lint`

## Lab materials

- Instructions: `StarterLab04/Readme.md`
- Existing submissions: `StarterLab04_Results/`
- The imported Decrement button increases the count. This behavior is preserved for the lab, not fixed as part of environment setup.
